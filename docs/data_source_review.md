### 1.1 업무 배경

온라인 뷰티 커머스에서 상품 탐색, 장바구니, 구매 관련 행동을 분석하기에 앞서 원천 이벤트 데이터의 구성과 신뢰성을 파악한다. 본 검토는 실제 기업 내부 데이터를 대상으로 수행한 업무가 아니라 공개 데이터 기반의 독립 분석 프로젝트다.

### 1.2 검토 원칙

- **관찰 사실**, **해석·가설**, **추가 검증 사항**을 분리한다.
- 이벤트 수를 사용자 수, 세션 수, 주문 수와 혼동하지 않는다.
- 데이터 품질 이슈가 발견되어도 검증 없이 원본 행을 삭제하거나 값을 변경하지 않는다.
- 표시한 비율은 전체 20,692,840행 또는 해당 월 이벤트 수를 분모로 계산한다.

## 3. 데이터 구조 및 행 단위(Grain)

### 3.1 컬럼 구성

| 컬럼 | 관측 자료형(원본 5행 샘플 기준) | 업무상 의미(예상) | 전체 결측 건수 | 비고 |
|---|---|---|---:|---|
| `event_time` | `str` | 이벤트 발생 시각 | 0 | UTC 파싱 검사 성공 |
| `event_type` | `str` | 행동 이벤트 종류 | 0 | 실제 4종 확인 |
| `product_id` | `int64` | 상품 식별자 | 0 | 상품 마스터 존재 여부 미확인 |
| `category_id` | `int64` | 카테고리 식별자 | 0 | 코드 결측의 대안으로 검토 |
| `category_code` | `float64` | 카테고리 코드(추정) | 20,339,246 | 5행 샘플에서 전부 NaN이라 float로 추론됨; 전체 CSV 자료형으로 일반화 금지 |
| `brand` | `str` | 브랜드 | 8,757,117 | 결측 많음 |
| `price` | `float64` | 이벤트에 기록된 가격 | 0 | 값의 단위·음수 의미 확인 필요 |
| `user_id` | `int64` | 사용자 식별자 | 0 | 식별자 고유성·지속성 확인 필요 |
| `user_session` | `str` | 세션 식별자 | 4,598 | 일부 결측 |

**자료형 해석 주의:** 이 표의 자료형은 `read_csv(..., nrows=5)` 같은 작은 샘플 읽기 결과에 해당한다. 전체 파일을 읽은 이전 탐색에서는 `category_code`가 문자열로 관찰된 바 있으므로 `float64`를 해당 컬럼의 확정 스키마로 사용할 수 없다. 식별자는 숫자형이어도 산술 계산 대상이 아니다.

### 3.2 행 단위

- **잠정 정의:** 한 행은 특정 시점에 특정 사용자·세션·상품에 기록된 **행동 이벤트 한 건**을 의미한다.
- **분석상 의미:** `purchase` 행은 **구매 이벤트 1건**이지, 주문 ID를 가진 주문 원장 1건이라는 보장이 없다.
- **추가 검증:** 동일 값의 반복 이벤트 발생 원인, 사용자·세션 식별자의 범위, 상품 단위 이벤트와 주문 단위의 차이를 점검해야 한다.

**ISSUE-001 — category_code 고결측**

- **사실:** 약 98.29%의 이벤트에 `category_code`가 없다.
- **영향:** 이 컬럼을 직접 사용한 카테고리별 성과 비교는 대표성이 크게 제한될 수 있다.

**ISSUE-002 — brand 결측**

- **사실:** 약 42.32%의 이벤트에서 브랜드가 없다.
- **영향:** 브랜드별 성과 분석 시 결측 행을 제외하면 분석 대상이 왜곡될 수 있다.

**ISSUE-003 — user_session 일부 결측**

- **사실:** 4,598건(약 0.0222%)에서 세션 식별자가 없다.
- **영향:** 세션 기반 퍼널과 세션 수 계산에서 일부 이벤트를 연결할 수 없다.

## 8. 종합 검토 의견

### 8.1 확인된 사실

1. 2019년 10월부터 2020년 2월까지 CSV 5개에서 총 **20,692,840건**의 이벤트가 관측되었다.
2. 9개 컬럼과 4개 이벤트 종류(`view`, `cart`, `remove_from_cart`, `purchase`)가 확인되었다.
3. 주요 식별자·이벤트 유형·시각 정보는 존재하지만 카테고리 코드와 브랜드에는 상당한 결측이 있다.
4. 전체 컬럼 일치 중복 후보와 0·음수 가격이 관찰되었다.
5. 날짜 파싱 실패는 0건이었다.

### 8.2 업무적 해석

상품·사용자 행동 분석의 **기초 원천 데이터로는 활용 가능성이 높다**. 그러나 `category_code` 결측과 동일 행 중복 후보는 지표 신뢰도에 영향을 줄 수 있다. 또한 관측된 구매 이벤트를 실제 주문·순매출과 동일시해서는 안 된다.

### 8.3 잠정 결론

**판정: 조건부 사용 가능(초기 행동 분석용)**

- 허용 범위: 이벤트 유형별 수, 상품 조회·구매 이벤트 수, 기준을 정의한 사용자 활동·세션 행동 분석의 준비 작업.
- 보류 범위: 주문 건수·정산 순매출 확정, 인과효과 주장, 품질 검증 없는 전환율 공표.
- 최종 승인 조건: 중복·가격 예외 처리 원칙, 카테고리 매핑, 사용자·세션 식별자와 시간대 기준을 문서화한다.

### 8.4 다음 작업 권고

1. **TASK-001 마무리:** 사용자·세션 고유값 수와 범위, 중복 후보의 이벤트 유형별 분포, 가격 0·음수의 이벤트 유형별 분포를 추가 확인한다.

3. **데이터 마트 설계 전:** 행 단위, 식별자, 중복 및 결측 처리, UTC/로컬 날짜 기준을 확정한다.
